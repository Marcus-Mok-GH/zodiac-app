## 📱 App Features

The zodiac app includes:
- **Birth Date Input**: Select your birth date from an interactive date picker
- **Zodiac Sign Detection**: Automatically determines your zodiac sign
- **Detailed Zodiac Information**:
  - Sign name with emoji
  - Date range
  - Ruling planet
  - Element (Fire, Earth, Air, Water)
  - Personality traits
  - Compatibility information
- **Beautiful UI**: Responsive design with Tailwind CSS
- **Smooth Animations**: Fade-in effects and interactive elements

## 📝 Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/Marcus-Mok-GH/zodiac-app.git
cd zodiac-app

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000 in your browser
```

## 🚀 Production Build

```bash
# Build for production
npm run build

# Start production server
npm start
```
