# Zodiac Sign Prediction App

A beautiful, interactive web application that predicts your zodiac sign based on your birth date.

## Features

- 🌙 Accurate zodiac sign calculation
- 🎨 Beautiful gradient UI with Tailwind CSS
- ⚡ Fast and responsive design
- 📱 Mobile-friendly interface
- ✨ Display zodiac symbol, element, and personality traits

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Language**: JavaScript/React

## Getting Started

### Prerequisites
- Node.js 16+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Deployment to Vercel

### Option 1: Using Vercel CLI

```bash
npm install -g vercel
vercel
```

### Option 2: GitHub Integration

1. Push this repository to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Select your GitHub repository
5. Vercel will auto-detect Next.js settings
6. Click "Deploy"

## How It Works

The app uses an algorithm to match your birth date to the appropriate zodiac sign, displaying:
- **Zodiac Symbol**: The astrological symbol
- **Element**: Fire, Earth, Air, or Water
- **Traits**: Key personality characteristics associated with your sign
